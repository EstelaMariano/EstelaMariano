# 👾 `ABOUT_ME`

Sou estudante de **Engenharia de Software na FIAP**, movida pela curiosidade de entender como a tecnologia funciona e, principalmente, como transformá-la em soluções para problemas reais.

Ao longo da graduação, venho construindo projetos principalmente com **React, JavaScript, HTML e CSS**, explorando desde o desenvolvimento de interfaces e aplicações web até conceitos de **IoT, Edge Computing e sistemas inteligentes**.

Também já tive contato com tecnologias como **Python, C, Arduino, AWS, Docker, APIs REST e FIWARE**, ampliando minha visão sobre diferentes áreas da Engenharia de Software.

Gosto de projetos que vão além de simplesmente escrever código. Tenho interesse em entender o problema, pensar na experiência do usuário, estruturar a solução e descobrir como diferentes tecnologias podem trabalhar juntas para transformar uma ideia em um produto funcional.

Ainda estou explorando as diferentes possibilidades dentro da tecnologia e tenho interesse especial em aprofundar meus conhecimentos em **Back-End, Inteligência Artificial, Cloud Computing e Cybersecurity**.

Mais do que me prender a uma única área, meu objetivo neste momento é **construir uma base técnica sólida, experimentar diferentes tecnologias e descobrir até onde consigo levar cada projeto que desenvolvo**.

Durante a graduação venho desenvolvendo projetos que simulam cenários reais de mercado, trabalhando com **React, JavaScript, Python, C, Arduino, AWS, Docker, FIWARE, APIs REST e modelagem de software**.

Gosto de aprender indo além do funcionamento superficial: quero entender **por que algo funciona, como poderia funcionar melhor e como transformar conhecimento técnico em produto**.
